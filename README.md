# KEYTOOL

Atslēgu servisa vietne: https://keytool.lv

## Saturs
- Statiska vietne bez būvēšanas soļa: HTML, CSS un JavaScript.
- Hostings: Netlify (`_headers`, `_redirects`).
- Virtuālā asistenta zināšanas un cenas: `ai/index.html`, blokos `public-ai-data` un `public-ai-prices`.
- Neatbildētie jautājumi: Netlify Forms forma `neatbildetie-jautajumi`.

## Failu nosaukumi
Failiem mapē `assets` nosaukumā ir satura SHA-256 hash pirmās 12 zīmes. Mainot failu, atjauno nosaukumu un atsauces lapās.
